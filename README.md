# Webull / 富途 半导体双层量化策略（SOXL / SOXS）

一套围绕 **SOXX 三票趋势切换 + 夜盘抢跑战术 + 宏观利率紧缩门控** 构建的半导体杠杆 ETF（`SOXL` / `SOXS`）自动化量化与多模拟盘对照系统，支持 **富途 OpenD 24 小时统一实时行情**、**Webull 沙盒/实盘下单**、**三套模拟盘并排实时对照**、**本地只读网页仪表盘** 以及 **微信 ClawBot 私聊（ChatGPT/Codex & Gemini 双引擎）与成交推送**。

---

## 一、核心策略逻辑与规则

系统只交易 **SOXL（3 倍做多半导体）** 与 **SOXS（3 倍做空半导体）**，每次全仓（按配置仓位比例）买入整股，无融资、无盈利加仓，统一使用覆盖当前交易时段的 `DAY` 限价单（买入限价较报价上浮 `0.3%`，卖出限价下浮 `0.3%`）。

### 1. SOXX 三票制趋势切换（决定核心层 vs 战术层）

每日使用 **SOXX** 前一交易日已完成日线计算三张投票，每票取 `+1` / `0` / `-1`：
1. **唐奇安通道（20 / 10）**：突破近 20 日高/低点入场，跌破/突破 10 日低/高点退出；
2. **SMA50 + 20 日动量**：收盘在 50 日均线上方且 20 日动量 > 0 为 `+1`，反之为 `-1`；
3. **EMA 10 / 30**：快线在慢线上方为 `+1`，下方为 `-1`。

| SOXX 总票数 | 趋势判定 | 执行方式 |
|---|---|---|
| **+2 至 +3** | 上涨趋势 | **核心层接管**：美东 `09:30` 后买入 `SOXL` 并可持仓过夜 |
| **−1 至 +1** | 震荡过渡 | 清空核心仓，切入 **夜盘战术层**（满足门控时允许双向） |
| **−3 至 −2** | 下跌趋势 | 清空核心仓，切入 **夜盘战术层**（仅允许做空 `SOXS`，禁做多） |

### 2. 核心层规则（日内移动止损 + 常规盘强势买回）
- **持仓移动止损**：从前一晚美东 `20:00` 夜盘开盘起，连续记录该美股交易日已收盘 1 分钟 K 线的最高价（覆盖夜盘、盘前、常规盘和盘后）。价格相对当日最高价回撤 **12%** 时提交卖单。新交易日重新计算高点。
- **强势买回**：若上涨趋势延续（三票仍 ≥ `+2`），自止损后的下一个美股交易日起，在常规盘（`RTH`）价格达到上一交易日常规盘收盘价的 **105%** 时买回核心仓。等待买回期间，夜盘战术信号仅允许顺势做多。

### 3. 夜盘战术层规则（亚洲盘共振 + 路径否决）
- **入场扫描**：美东 `21:00` 起每分钟连续扫描（A 版 / 原版扫至 `04:00`，B 版防收割扫至 `23:59` 停掉深夜追单）。
  - `SOXL` 相对上一交易日常规盘收盘价涨跌达到 **±3%**；
  - 韩国综合指数 **KOSPI（`^KS11`）** 当天同方向涨跌达到 **±1%**（韩国休市跳过）；
  - **6% 路径否决**：做多要求未从昨收以来高点回落 ≥6%，做空要求未从低点反弹 ≥6%。
- **宏观利率双紧缩门控（A 版 / B 版开启）**：
  - 使用前一交易日已完成日线，要求 **13 周短债收益率 `^IRX` 与 10 年期美债收益率 `^TNX` 同时高于各自 60 日均线（`SMA60`）** 时，才允许夜盘做空 `SOXS`；
  - 在降息/流动性宽松期（逢跌易低开高走 V 形反抽）自动关闭夜盘追空，防止被反抽收割；核心层做多与战术做多不受限制。
- **退出与买回**：
  - 首腿跌破均价 **6%** 固定止损，或从持仓最高价回撤 **8%** 移动止损；
  - **第二腿买回**（A 版 / 原版开启，B 版关闭）：卖出后若在美东 `15:00` 前从卖出后低点反弹 **3%**，按原方向全仓买回一次，第二腿设成本下方 **6%** 固定止损；
  - 战术持仓统一在美东 `15:55`（半天市 `12:55`）前清仓，不留隔夜。

### 4. 暴跌极值反转抓底模块（模式 A · 已全量接入三套模拟盘）
- **核心逻辑**：针对 3 倍杠杆 ETF 单日暴跌触发的强制去杠杆与 15:50–16:00 ET 尾盘再平衡砸盘，在常规盘收盘后用 **1 分钟 K 线** 右侧确认情绪出清，临时接管次日战术层（豁免三票方向与利率门控，且不与核心仓冲突）：
  - **唤醒阈值**：`SOXL` 或 `SOXS` 当日常规盘收盘相对前日收盘暴跌 **≤ −25%**；
  - **1 分钟右侧确认窗口**：常规收盘后（`16:00 ET`，半日市 `13:00 ET`）至次日 **`09:45 ET`**，需同时满足：
    1. 1 分钟线连续 **20 分钟不创盘后/夜盘新低**；
    2. 当前 1 分钟收盘价从最低点反弹 **≥ +2%**；
    3. 当前 1 分钟收盘价站上 **`EMA20(1m)`**；
  - **独立风控退出**：固定硬止损 **−10%**（截断类似 2025-04 关税连环崩盘的飞刀风险）；浮盈 **≥ +12%** 后启动 **10% 最高价回撤移动止盈**；否则持有至次日 **`15:55 ET`**（半日市 `12:55 ET`）自动平仓结算。

## 三、统一实时行情源（富途 OpenD 24h）

系统通过 `config.yaml` 中的 `swing.market_source` 统一配置实时行情来源（支持 `futu` / `webull` / `auto`，默认 **`futu`**）：

- **为什么统一用富途行情**：Webull 沙盒可读取 `OVN` 夜盘 K 线，但 Webull 生产环境（`prod`）未单独订阅 `NIGHT TRADING STOCK QUOTES` 时会返回 `403 MARKET_DATA_NOT_SUBSCRIBED`。使用本机富途 OpenD `Session.ALL` 订阅 1 分钟 / 5 分钟实时行情（`FutuMarket`）：
  - 与 Webull M1 收盘价中位误差 < `0.02%`（常规盘 `0.00%`）；
  - 实时订阅不消耗历史 K 线额度，内置断线自动重连与 `04:00` 昨收假针过滤；
  - 实盘时可直接「**富途行情 + Webull 实盘下单**」，无需重复购买 Webull 夜盘行情订阅。
- **Webull 下单容错**：`WebullClient` 已配置 `connect_timeout=10s`、`timeout=15s`（关闭自动重发以避免重复下单）。
- **其他外部数据**：KOSPI 5 分钟/日线与 `^IRX` / `^TNX` 利率日线取自 Yahoo Finance 公开接口，均严格只用已完成 K 线，无未来函数。

## 四、安装与运行

### 1. 环境初始化

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
# 需使用富途行情或富途模拟/影子模式时安装可选依赖：
.venv/bin/python -m pip install "futu-api>=10.12,<11"

cp .env.example .env
# 在 .env 中填写 WEBULL_SANDBOX_APP_KEY / SECRET（以及实盘密钥）
.venv/bin/python -m wquant check
.venv/bin/python -m wquant futu-check
```

### 2. 日常运行与三套模拟盘管理

```bash
# 查看三套模拟盘并排实时对比（权益、收益率、回撤、持仓、利率门控、最新日志）
.venv/bin/python -m wquant paper-arena status

# 启动单套主策略（默认 config.yaml 为更新后的 A 版）
.venv/bin/python -m wquant run --mode webull --watch          # Webull 沙盒/实盘
.venv/bin/python -m wquant run --mode paper --profile plan_b  # 单独本地模拟运行
.venv/bin/python -m wquant run --mode futu-sim --profile plan_b  # 富途美股模拟盘（仅锁定 SIMULATE 账户）
.venv/bin/python -m wquant run --mode futu-shadow --watch     # 富途影子报价（只打印不报单）

# 单进程共享行情同步运行 B 版 + 原版基准（与 Webull 沙盒的 A 版互补，避免重复下单）
.venv/bin/python -m wquant paper-arena run --watch --companions-only --b-mode paper

# 启动本地只读网页仪表盘（http://127.0.0.1:8765，顶部直接展示三套模拟盘实时对比）
.venv/bin/python -m wquant dashboard
```

**常用安全与辅助命令：**
- 实盘下单三重保护：必须同时满足 `WEBULL_ENVIRONMENT=prod`、`config.yaml` 中 `live_trading_enabled: true` 和命令行 `--confirm-live`。
- 紧急熔断：在项目根目录创建 `KILL_SWITCH` 文件可立即停止所有新开仓。
- 双账户全仓预算只读预检：
  ```bash
  .venv/bin/python -m wquant full-buy-plan SOXL --limit 32.12 --session overnight --webull-account-suffix XXXX
  ```

### 3. macOS 后台守护进程部署

先核对 `deploy/*.plist` 中的项目路径，再运行安装脚本一键部署全部 4 个后台进程：
- `com.webullquant.tactical`：A 版（利率双开关）→ Webull 沙盒
- `com.webullquant.arena`：B 版（防收割）+ 原版（2026 基准）→ 双本地实时模拟盘
- `com.webullquant.dashboard`：本地只读仪表盘（`http://127.0.0.1:8765`）
- `com.webullquant.wechat`：微信通知推送与 ClawBot 私聊服务

```bash
bash deploy/install.sh     # 安装并启动全部后台服务
bash deploy/uninstall.sh   # 停止并移除后台服务
```

> **本机运行注意事项：**
> - 任务运行在本机时需保持 **开机、联网、富途 OpenD 登录在线**；
> - `plist` 中已使用 `caffeinate -i` 防止**开盖闲置休眠**（可息屏），但**直接合上笔记本盖子**（未接外接显示器）仍会触发系统休眠断网并暂停策略。如需长期 7×24 无人值守，建议部署到云主机。

用手机微信扫码确认后，在 ClawBot 对话里发送「帮助」即可激活会话：
- **策略与账户指令**（本地直接执行，绝不经过大模型）：
  - `策略状态`：同时查看 A 版 / B 版 / 原版三套模拟盘的实时权益、收益率、持仓与利率门控；
  - `最近回测`、`Webull 模拟盘持仓`、`富途持仓`；
  - `买入 SOXL 2 股 限价 32.10`：预检 Webull 模拟盘整股限价单，3 分钟内回复返回的 8 位确认码才会提交；回复 `取消草稿` 清空待确认草稿。

### 2. 普通问答模型（支持 ChatGPT/Codex 与 Gemini 自由切换）

系统支持 4 种问答通道，均运行在隔离环境且**绝不透传券商密钥**，并自动注入最新策略资料：

1. **本机 ChatGPT / Codex CLI**（已登录 `ChatGPT.app` 内置 Codex 时开箱即用，免 API Key）；
2. **本机官方 Gemini CLI（个人 Google 账号免 API Key）**：
   ```bash
   npm install -g @google/gemini-cli
   gemini   # 首次启动选择 "Login with Google" 浏览器授权后 Ctrl+C 退出
   ```
3. **Gemini API Key（2–4 秒秒回，默认 `gemini-2.5-flash`）**：
   ```bash
   .venv/bin/python -m wquant wechat chat-gemini-setup
   ```
4. **OpenAI Responses API Key（可选备用，默认 `gpt-5-mini`）**：
   ```bash
   .venv/bin/python -m wquant wechat chat-gpt-setup
   ```

**微信私聊内随时切换模型：**
- `切换 Gemini` / `切换 GPT` / `切换自动`（自动模式在已配 Gemini API Key 时优先 Gemini，失败自动回退 Codex → OpenAI API）
- `当前模型`：查看当前默认引擎及各模型就绪状态
- `Gemini 今天半导体怎么看` / `GPT 帮我总结一下`：单次指定引擎回答，不改变默认设置

### 3. 微信公众号成交通知（PushPlus / WPush）
